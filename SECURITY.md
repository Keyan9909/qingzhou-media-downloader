# Security policy

## Reporting a vulnerability

Please open a GitHub security advisory instead of a public issue when a report could expose credentials, browser data, local files, or a method for bypassing access controls.

Never attach passwords, one-time codes, cookies, browser profiles, API keys, private media, or personal logs. Replace sensitive values with minimal redacted examples.

## Supported scope

The project is designed for local use and authorized content only. Reports about bypassing DRM, paywalls, account permissions, or other access controls are outside the supported scope.
