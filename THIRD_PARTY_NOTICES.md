# Third-party components

This source repository depends on third-party projects installed separately from `requirements.txt`.

- `yt-dlp` — Unlicense for the source distribution; bundled executables can contain components under additional licenses.
- `requests` — Apache-2.0.
- `imageio-ffmpeg` — BSD-2-Clause; bundled FFmpeg binaries have their own LGPL/GPL configuration-dependent terms.
- `psutil` — BSD-3-Clause.
- `PyInstaller` — GPL-2.0-or-later with an exception for distributing generated bundles.

This file is a summary, not a substitute for the license files shipped by each dependency. If you distribute a binary build, include the exact notices and corresponding source obligations for the versions and binaries you bundle.
